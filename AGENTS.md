# Instrucciones de mantenimiento de Nexus Chat

## Sincronización autorizada con GitHub

El propietario ha solicitado expresamente que cada futura actualización de la página se suba también a https://github.com/Josxe155/Nexus-Chat, sin tener que pedirlo de nuevo.

- Después de implementar y verificar una actualización de Nexus Chat, guarda los cambios correspondientes en un commit y súbelos al repositorio, respetando las protecciones de la rama y los cambios existentes de otros colaboradores.
- Esta autorización incluye las actualizaciones de código, recursos, reglas y documentación relacionadas con la página. No publiques trabajos ajenos a Nexus ni cambios que aún no estén listos.
- Mantén el README coherente con las funciones y el modelo de seguridad vigentes. Conserva su presentación con insignias, tablas y secciones claras.
- No subas claves de proveedores, configuraciones locales con secretos, cuentas de servicio, bases de datos, datos de usuarios, archivos temporales, node_modules ni dist. Respeta .gitignore y utiliza la plantilla de servicios sin claves.
- Comprueba que los archivos enviados coincidan con los cambios verificados. No fuerces una actualización que sobrescriba commits de otras personas.
- Si el acceso a GitHub está bloqueado, conserva el trabajo local e informa de la sincronización pendiente; no afirmes que se ha subido.
- GitHub y Firebase Hosting son publicaciones distintas. Subir un commit no equivale a desplegar la web. Ejecuta solo las publicaciones autorizadas para el trabajo de la sesión.
