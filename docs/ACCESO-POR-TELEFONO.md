# Acceso por teléfono retirado

El acceso y la verificación por SMS se retiraron del proyecto. Este documento sustituye la descripción histórica del formulario antiguo para evitar presentarlo como una función disponible.

Los números que aparecen actualmente en el perfil son identificadores internos de Nexus Chat, no líneas telefónicas verificadas. Nuevo contacto utiliza ese número para encontrar una cuenta existente; no envía SMS ni acredita la titularidad de una línea real.

Consulta [Nuevo contacto](NUEVO-CONTACTO.md) para el funcionamiento vigente y [Registro y protección](REGISTRO-Y-PROTECCION.md) para los antecedentes del acceso.
