Nexus Chat — lectura de voz v26.99.0

Esta versión reproduce audio MP3 del servicio de voz de Google Translate.
No distribuye KokoroJS, Transformers, ONNX Runtime ni eSpeak como motor de voz.
No ejecuta Python ni instala la biblioteca gTTS dentro del navegador.

Documentación de gTTS, biblioteca Python que utiliza el servicio de Translate:
https://gtts.readthedocs.io/en/stable/
Integración web, privacidad y límites:
https://github.com/Josxe155/Nexus-Chat/blob/main/docs/VOZ-GOOGLE-26.99.0.md

El texto seleccionado para escuchar se envía al servicio externo y requiere
conexión. Este endpoint web no ofrece un contrato de disponibilidad de API.
